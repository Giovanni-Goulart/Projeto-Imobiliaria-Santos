# 🏡 Imobiliária Santos

Projeto de site institucional para uma imobiliária, desenvolvido com foco em **design moderno, responsividade e boa experiência do usuário (UX/UI)**.

[Acessar o site](https://giovanni-goulart.github.io/Projeto-Imobiliaria-Santos/)
---

## 📌 Sobre o projeto

Este projeto apresenta uma página web para a **Imobiliária Santos**, com o objetivo de divulgar serviços, apresentar a empresa e facilitar o contato com clientes interessados em imóveis.

O site foi desenvolvido utilizando tecnologias web básicas, com boas práticas de estruturação e organização.

---

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3
* Google Fonts
* Layout Responsivo (Media Queries)

---

## 🎨 Funcionalidades

* ✅ Menu de navegação com âncoras
* ✅ Banner principal
* ✅ Seção "Sobre"
* ✅ Seção de serviços
* ✅ Apresentação de corretores
* ✅ Integração com Google Maps
* ✅ Design responsivo para mobile e desktop

---

## 📱 Responsividade

O site foi desenvolvido para funcionar em:

* 📱 Smartphones
* 📲 Tablets
* 💻 Desktops

Utilizando **Media Queries e boas práticas de layout fluido**.
